🍱 AI-Based Food Recognition and Calorie Estimation System 

This project is designed to help health-conscious individuals track their food intake by recognizing food items, estimating portion sizes, and calculating nutritional values using computer vision and deep learning. The system also includes a chatbot for food suggestions and an alert mechanism to warn users about unhealthy food.

📌 Problem Statement
Managing a healthy diet can be challenging, especially when estimating portion sizes and tracking nutrition. This project aims to automate this process by:
Detecting food items from images 
Estimating portion size and nutritional values
Recommending healthier alternatives

🔍 Key Features
🧠 Food Detection: Identifies Indian food items using YOLOv8 with 92% accuracy (outperforms YOLOv5).

📏 Portion Estimation: Estimates portion size and weight to calculate calorie intake.

📊 Nutritional Analysis: Computes nutrients (calories, protein, carbs, fats) per meal.

🤖 COnSUltation Support: Connectin with doctors related to any food enquiry.

📅 Report Generation: Creates weekly/monthly summaries for diet tracking.

⚙️ Technologies Used
Python, OpenCV, YOLOv8, Detectron2

Firebase – for user authentication and data storage

Streamlit / HTML-CSS-JS (optional) – for user interface

Pandas, NumPy, Matplotlib – for data handling and visualization
